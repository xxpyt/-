# 仿真实验方案

## 1. 实验目标

本实验方案用于支撑毕业设计中“仿真与分析”部分，重点完成以下任务：

1. 验证 `ASK`、`FSK`、`PSK`、`DPSK` 系统结构的正确性。
2. 比较四种调制方式在不同信噪比条件下的抗干扰能力。
3. 分析各调制方式的波形、频谱和误码率特性。
4. 为论文结论提供可量化依据。

## 2. 实验环境

1. 仿真平台：`System View`
2. 研究对象：数字频带通信系统
3. 对比对象：`ASK`、`FSK`、`BPSK`、`DPSK`
4. 基础信道：理想信道、`AWGN` 信道

## 3. 基础实验参数

建议统一使用以下参数：

1. 码元速率：`1 kbps`
2. 码元周期：`1 ms`
3. 采样频率：`100 kHz`
4. 载波频率：`10 kHz`
5. 比特序列长度：`1000`
6. 信噪比：`0 dB`、`2 dB`、`4 dB`、`6 dB`、`8 dB`、`10 dB`、`12 dB`、`14 dB`、`16 dB`、`18 dB`、`20 dB`

## 4. 实验一：无噪声条件下的系统正确性验证

### 4.1 目的

验证四种调制方式在理想信道条件下能够正确完成发送与接收。

### 4.2 观察内容

1. 原始码流与恢复码流是否一致。
2. 已调信号波形是否符合理论特征。
3. 解调输出是否能够恢复出原始信息。

### 4.3 预期结果

1. 四种系统都应能正确恢复原始码流。
2. 误码率应接近 `0`。

## 5. 实验二：不同信噪比下的误码率测试

### 5.1 目的

比较不同调制方式在 `AWGN` 条件下的误码性能。

### 5.2 步骤

1. 固定系统基础参数。
2. 逐步改变 `SNR`。
3. 分别记录四种调制方式对应的误码率。
4. 绘制误码率随信噪比变化曲线。

### 5.3 重点分析

1. 哪种调制方式在低信噪比下误码更低。
2. 哪种调制方式对噪声更敏感。
3. 哪种调制方式更适合工程实现。

## 6. 实验三：波形与频谱分析

### 6.1 目的

观察不同调制方式在时域与频域上的差异。

### 6.2 观察内容

1. 基带输入波形。
2. 已调信号时域波形。
3. 接收端解调输出波形。
4. 各调制方式频谱分布特征。

### 6.3 论文分析角度

1. `ASK` 主要体现在幅度变化。
2. `FSK` 主要体现在频率切换。
3. `PSK` 主要体现在相位翻转。
4. `DPSK` 主要体现在相邻码元相位差变化。

## 7. 实验四：抗干扰能力综合比较

### 7.1 综合评价指标

可从以下维度综合比较：

1. 误码率高低
2. 接收结构复杂度
3. 对同步要求高低
4. 抗噪声能力
5. 工程实现难度

### 7.2 预期结论方向

1. `ASK` 实现简单，但抗噪声能力偏弱。
2. `FSK` 抗干扰性能较好，接收结构中等复杂。
3. `BPSK` 通常具有较优误码性能，但相干解调对同步要求高。
4. `DPSK` 解调实现较方便，综合性能较好。

## 8. 论文中可直接使用的结果组织方式

建议把实验结果整理成以下形式：

1. 各调制方式系统结构图
2. 各调制方式典型波形图
3. 各调制方式频谱图
4. `SNR-BER` 对比表
5. `SNR-BER` 曲线图
6. 性能综合比较表

## 9. 结果填写规范

1. 每个实验至少保存一次典型截图。
2. 每组参数变化都要记录 `SNR` 与 `BER`。
3. 图表标题和参数值必须统一。
4. 所有分析结论必须回到任务书中的“不同调制方式比较”和“抗干扰能力分析”两个核心要求。
