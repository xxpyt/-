# System View 搭建指南

## 1. 搭建原则

为了保证四种调制方式的仿真结果具有可比性，建议所有模型遵循以下原则：

1. 使用相同的随机码源长度。
2. 使用统一的码元速率与采样频率。
3. 除调制模块外，尽量保持信道与观测模块一致。
4. 每种调制方式分别建立独立模型，便于截图和参数说明。

## 2. 通用模块链路

所有调制系统都可以从如下基础链路开始搭建：

```text
随机码源 -> 基带成形 -> 调制器 -> AWGN信道 -> 解调器 -> 低通/判决 -> 误码率统计
```

建议同时接入以下观察模块：

1. 时域波形显示模块
2. 频谱显示模块
3. 误码率统计模块

## 3. ASK 系统搭建

### 3.1 发送端

建议模块链路：

```text
随机二进制码源 -> 单极性NRZ变换 -> 乘法器 -> ASK已调信号
                              ↑
                           正弦载波源
```

### 3.2 信道

```text
ASK已调信号 -> AWGN信道
```

### 3.3 接收端

可采用包络检波方案：

```text
AWGN输出 -> 包络检波 -> 低通滤波 -> 抽样判决 -> 恢复码流
```

也可采用相干解调方案：

```text
AWGN输出 -> 乘法器 -> 低通滤波 -> 抽样判决 -> 恢复码流
                 ↑
              同步载波
```

### 3.4 关键参数

1. 载波频率：`10 kHz`
2. 码元速率：`1 kbps`
3. 载波幅度：`1`
4. 判决门限：`0.5`

## 4. FSK 系统搭建

### 4.1 发送端

建议模块链路：

```text
随机二进制码源 -> 电平映射/频率控制 -> FSK调制器 -> FSK已调信号
```

实现方式可选：

1. 使用受控振荡器，根据输入比特切换不同输出频率。
2. 分别生成 `f1` 和 `f2` 两路载波，再由开关模块选择输出。

### 4.2 信道

```text
FSK已调信号 -> AWGN信道
```

### 4.3 接收端

建议使用双通道频率选择方案：

```text
AWGN输出 -> 带通滤波器1 -> 包络检波1 --
                                     |-> 比较判决 -> 恢复码流
AWGN输出 -> 带通滤波器2 -> 包络检波2 --
```

### 4.4 关键参数

1. `f1 = 12 kHz`
2. `f2 = 8 kHz`
3. 码元速率：`1 kbps`
4. 两路带通滤波器中心频率分别对应 `f1` 和 `f2`

## 5. PSK 系统搭建

### 5.1 发送端

建议采用 `BPSK` 结构。

模块链路：

```text
随机二进制码源 -> 双极性变换(+1/-1) -> 乘法器 -> BPSK已调信号
                                   ↑
                                正弦载波源
```

### 5.2 信道

```text
BPSK已调信号 -> AWGN信道
```

### 5.3 接收端

建议采用相干解调：

```text
AWGN输出 -> 乘法器 -> 低通滤波 -> 抽样判决 -> 恢复码流
                 ↑
              同步载波
```

### 5.4 关键参数

1. 载波频率：`10 kHz`
2. 码元速率：`1 kbps`
3. 双极性映射：`1 -> +1`，`0 -> -1`
4. 判决门限：`0`

## 6. DPSK 系统搭建

### 6.1 发送端

建议模块链路：

```text
随机二进制码源 -> 差分编码 -> 双极性变换 -> 乘法器 -> DPSK已调信号
                                             ↑
                                          正弦载波源
```

### 6.2 信道

```text
DPSK已调信号 -> AWGN信道
```

### 6.3 接收端

建议采用延时比较法：

```text
AWGN输出 -> 延时单元 -> 乘法器 -> 低通滤波 -> 抽样判决 -> 差分译码 -> 恢复码流
      \_____________________/
            当前信号与前一码元比较
```

### 6.4 关键参数

1. 载波频率：`10 kHz`
2. 延时长度：`1 个码元周期`
3. 差分编码初始参考位：`1`

## 7. 统一观察点设置

为了方便论文截图，建议每个模型至少保留以下观察点：

1. 原始二进制序列输出点
2. 基带映射输出点
3. 已调信号输出点
4. 加噪后信号输出点
5. 解调后基带输出点
6. 判决恢复码流输出点

## 8. 仿真结果建议截图内容

每种调制方式建议至少保留以下截图：

1. 系统整体连接图
2. 发送端已调波形
3. `AWGN` 信道输出波形
4. 接收端恢复波形
5. 频谱图
6. 误码率结果图或统计值

## 9. 建模顺序建议

为了降低出错概率，建议按以下顺序逐步搭建：

1. 先搭建 `BPSK`，因为结构最清晰，便于验证接收判决链路。
2. 再搭建 `ASK`，用于对比幅度调制的抗噪声性能。
3. 然后搭建 `FSK`，重点验证频率切换与双路接收。
4. 最后搭建 `DPSK`，重点处理差分编码与延时检测。
