# 仿真系统运行说明（升级版）

## 1. 如何打开

直接打开 `simulator/index.html` 即可运行，不需要 `npm install`。

## 2. 新增能力

1. 固定随机种子，可复现实验结果。
2. `ASK/FSK/BPSK/DPSK` 的仿真 BER 与理论 BER 同图对照。
3. 导入实测数据评估 BER：
   - `tx_bits.csv`：发送端比特（`0/1`，逗号或换行分隔）
   - `rx_samples.csv`：接收端采样（浮点数，逗号或换行分隔）
4. 一键导出：
   - `ber_sweep_results.csv`
   - `实验报告-自动生成.md`

## 3. 推荐使用流程

1. 设置参数并填写随机种子。
2. 先运行“单次仿真”检查波形。
3. 运行“BER 对比”生成曲线并导出 CSV。
4. 如有实测数据，使用“导入实测数据评估”计算真实 BER。
5. 导出自动报告，作为论文实验章节草稿。

## 4. 注意

1. 导入评估依赖“每码元采样点”等参数，需与采样数据生成时一致。
2. 若曲线抖动较大，增大比特数与重复次数。
