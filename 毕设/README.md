# 基于 System View 的数字频带通信系统仿真与分析

## 项目说明

本项目依据[任务书](c:\Users\ASUS2308\Desktop\毕设\任务书.md)建立，目标是完成一个用于毕业设计的数字频带通信系统仿真方案，并围绕 `ASK`、`FSK`、`PSK`、`DPSK` 四种典型数字频带调制方式开展系统设计、参数配置、信道仿真与性能分析。

当前目录中的内容并不是某一款专有软件导出的工程文件，而是一套可直接用于 `System View` 搭建、实验记录、论文撰写和答辩准备的完整系统设计包。

## 项目结构

- `任务书.md`
  任务书的 Markdown 转写版，后续所有材料的依据。
- `README.md`
  项目总体说明。
- `docs/系统总体设计.md`
  系统目标、总体架构、关键技术路线和分析指标。
- `docs/SystemView搭建指南.md`
  在 `System View` 中搭建各个调制系统的具体步骤与模块链路。
- `docs/仿真实验方案.md`
  实验设计、对比维度、结果记录和论文写作建议。
- `data/参数配置表.csv`
  系统及各调制方式的参数基线。
- `data/实验结果记录模板.csv`
  后续填写仿真结果使用的统一模板。

## 系统研究范围

本毕设系统限定在以下范围内：

1. 研究对象为数字频带通信系统。
2. 仿真平台为 `System View`。
3. 调制方式至少包含 `ASK`、`FSK`、`PSK`、`DPSK`。
4. 信道条件以加性高斯白噪声信道（`AWGN`）为基础，可扩展理想信道与衰落信道。
5. 比较指标包括误码率、波形恢复情况、频谱特性和抗干扰能力。

## 交付思路

本系统包先解决三个核心问题：

1. 让你能在 `System View` 中按统一参数把系统搭起来。
2. 让你后续写论文时，系统结构、参数表、实验表、结论用同一套口径。
3. 让你后续补仿真截图、结果图和论文正文时不需要重新规划结构。

## 当前建议的实施顺序

1. 先阅读[系统总体设计.md](c:\Users\ASUS2308\Desktop\毕设\docs\系统总体设计.md)。
2. 再按照[SystemView搭建指南.md](c:\Users\ASUS2308\Desktop\毕设\docs\SystemView搭建指南.md)在软件中搭建模型。

4. 依据[仿真实验方案.md](c:\Users\ASUS2308\Desktop\毕设\docs\仿真实验方案.md)运行实验。
5. 将结果填入[data/实验结果记录模板.csv](c:\Users\ASUS2308\Desktop\毕设\data\实验结果记录模板.csv)。
