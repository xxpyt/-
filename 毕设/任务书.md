## 四、设计名称、任务与内容

### 1. 课题名称

数字频带通信系统的 System View 仿真与分析

### 2. 设计任务

在 System View 平台上构建完整的数字频带调制仿真系统。

### 3. 主要内容

数字频带调制技术是通信原理中的重要内容，也是数字通信系统中必不可少的一个环节。目前，数字频带通信系统中常用的调制技术包括 ASK、FSK、PSK、DPSK 等。

本课题研究的主要内容是在 System View 平台上建立各种数字频带调制技术的仿真模型，研究数字通信系统在不同信道条件下以及不同调制方式下的抗干扰能力。

### 4. 具体要求

1. 完成模块设置，确定搭建系统的主要参数。
2. 对数字频带通信系统不同调制方式进行全面的仿真分析和比较。
3. 模块及参数配置列表清晰，注释完整清楚。
